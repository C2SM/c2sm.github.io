# NCCR CLIM+

## Requesting a Task

Tasks for the [NCCR CLIM+ :material-open-in-new:](https://nccr-climplus.ch/){:target="_blank"} project can be requested as follows:

- Submit a new task using the [task submission template :material-open-in-new:](https://github.com/C2SM/climplus/issues/new?template=task-submission-template.md){:target="_blank"}.
- Track the status of submitted tasks on the [CLIM+ project board :material-open-in-new:](https://github.com/orgs/C2SM/projects/29){:target="_blank"}.

!!! info
    Both links require a GitHub account and membership in the CLIM+ user group within the C2SM organization.
