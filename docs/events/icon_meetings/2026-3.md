## Reports

### C2SM (Michael Jähn, Matthieu Leclair, Mikael Stellio, Alitzel Macías)

MJ mentioned that to be on the mailing list for this meeting one should register on the link in the C2SM landing page.

MJ welcomes everyone and shares the [latest news about ICON from C2SM :material-download:](https://polybox.ethz.ch/index.php/s/2ddZ43CLpEx83cK){:target="_blank"}.

CZ asked about the reason behind the name 'gpus-per-node' in the CSCS new changes, MK mentioned it was what was more convenient. He also confirmed that this flag is only for `srun` (not `SBATCH`) and that they are still working on the accounting, so that the user gets billed only for the gpus they are using, the estimated time for this is end of year.

MaL mentioned that when selecting the numa nodes you have to explicitly ask the system what socket it gave you, to make sure that the binding is correct.

CK asked about where to report issues with ICON, it is not very clear where to do this. MaL answered that it will get better once the repos are unified on icon/icon. Tina mentioned that it would be good to flag it internally and then C2SM reports it. This is because otherwise there is no one that is clearly responsible. MaL says that this is something that needs to be dicussed further, specially given the upcoming changes of only Nightly CI testing. CK's specific issue only happened with 24 nodes, which is why the bug was not catched with the CI.

Regarding the soil data, CZ says that he has a dataset that MS can compare with his current dataset to evaluate its correctness. MA was also interested in this dataset from CZ.
